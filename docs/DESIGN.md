# Manara design system

The supplied Home Screen1 and Quran2 references define the visual direction. Mobile is the authoritative composition. Desktop extends it using a quiet right-hand navigation rail and a two-column dashboard.

- Forest green `#104f40`, pale mint `#cce7df`, white surfaces and restrained gold prayer emphasis.
- Rounded cards, arch-shaped reciter portraits, outline icons, a pill-shaped mobile navigation bar.
- Tajawal UI type, Amiri Quran text, Aref Ruqaa brand approximation. The references are raster images, not original calligraphic vectors; the logo and surah titles are typographic approximations rather than exact artwork.
- Semantic theme variables in `src/styles.css`; conservative dark theme; RTL throughout.
- Quran reader displays one of the 604 pages using the source ayah page metadata, including multiple surahs on shared pages. Navigation is horizontal (buttons, keyboard arrows and swipe); there is no continuous vertical surah scroll. Text fits the viewport; exact printed line breaks are not claimed. The opening basmala has its own line, with Fatiha numbering preserved and no added basmala for Tawbah.
- Reader font slots `--font-surah-name`, `--font-juz-name`, `--font-ayah` are ready for the user's forthcoming font files.
- Reference viewport checked at 402 × 874. Desktop checked with the in-app browser's default viewport. Home cards, colors, rounded navigation and arches compared visually; no pixel-perfect claim.

Pages derived from the references: Quran index/search/juz/bookmarks, surah reader, reciter directory and recordings, adhkar category/detail views, tasbih, prayer schedule/location, preferences/account. The welcome transition uses the same brand and arches, has a skip action, and appears once per session.

### Supplied fonts applied
The three user-provided WOFF2 files are now active in the reader. The supplied basmala SVG replaces the textual opening visually while preserving its accessible label and Fatiha verse numbering. Surah/juz glyph IDs come from the font's own GSUB tables. Initial font loading triggers page refitting to avoid clipped text.

### Original brand assets
The shared header/sidebar Logo uses `public/images/Manara_App_H_Logo.svg` at its original aspect ratio. The favicon and install manifest use `Manara_App_Logo.svg`, with 180px Apple touch and 192/512px PNG exports generated by `node scripts/generate-icons.mjs`. Notification icons use the same supplied app artwork.
